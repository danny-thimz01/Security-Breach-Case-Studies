# Security Breach Case Studies

A quick look at five real breaches: what was taken, how attackers got in, and how each could have been prevented.

**Cases covered:** Target (2013), Equifax (2017), Capital One (2019), Colonial Pipeline (2021) and MOVEit (2023).

**What's in the table:** incident date, who was hit, what was taken, what exploits were used, how to prevent it, and a source link.

**The takeaway:** Most of these weren't fancy attacks. Missed patches, weak logins and misconfigured systems caused most of the damage.

**Files:** `Security_Breach_Case_Studies.xlsx` holds the full table.
